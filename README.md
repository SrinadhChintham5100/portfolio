# Srinadh C — Portfolio

Personal portfolio built with **React 18**, **Three.js** (via React Three Fiber), **Framer Motion** and **Vite**, deployed on **Netlify**.

## Quick start

```bash
npm install      # download dependencies (first time only)
npm run dev      # start local dev server → http://localhost:5173
```

## Production build

```bash
npm run build    # creates the optimized site in /dist
npm run preview  # serve /dist locally to check it before deploying
```

## Edit your content

Everything you see on the site lives in **`src/data.js`**. Change it, save, and the browser updates instantly.

- LinkedIn URL → `profile.linkedin`
- GitHub URL → `profile.github` (empty = hidden)
- Résumé download → replace `public/resume.pdf`
